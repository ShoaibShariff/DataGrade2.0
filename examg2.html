General Exam Writing Tips ✅ 1. Read the question carefully. Underline key words (like “Explain,” “Differentiate,” “Draw diagram,” “List,” “Write program”). This tells you what kind of answer the examiner expects. ✅ 2. Write in clean, neat handwriting. Leave one line space between points. Use underlining or bullet points for important terms. Draw diagrams using pencil and ruler. ✅ 3. Stick to what’s asked. Don’t overwrite or go off-topic. Examiners prefer short, correct, and well-structured answers. 🟩 How to Write 2-Mark Answers (Short / Objective Type) 📌 Goal: Be precise, factual, and quick. 💡 Each answer should take 3–4 lines only. ✴️ Format: Definition / Direct Answer — 1 line Example / Key point — 1 line (If applicable) — small formula or diagram ✴️ Example: Q: Define Compiler. A: A compiler is a language translator that converts an entire high-level program into machine code at once. Example: C++ uses a compiler to generate executable code. ✅ Tip: For 2-mark answers — Use keywords like “It is,” “They are,” “Used to,” “Example:” Avoid long explanations — short and straight to the point. If the question is numerical, show formula + one-line working. 🟨 How to Write 10-Mark Answers (Descriptive Type) 📌 Goal: Show knowledge, structure, and clarity. 💡 Spend 10–12 minutes per 10-mark question. ✴️ Ideal Format (Follow this for every long answer) Introduction (2 marks) Define the main term or concept. Give short background if needed. Explanation / Body (5–6 marks) Write important points in order using headings or bullet points. Underline key terms. Use diagrams / tables / flowcharts wherever possible — this makes a big impression! Give examples or small code snippets if it’s programming. Conclusion (1–2 marks) Summarize or mention importance/application.
